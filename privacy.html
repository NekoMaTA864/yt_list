yt_list 隱私權政策

最後更新日期：2026 年 9 月 16 日

yt_list 是供個人使用的自動化工具，用於讀取 YouTube 頻道的新影片、 分析音樂類型，並協助整理 YouTube 播放清單。

我們存取的資料

  • 經授權的 YouTube 頻道、上傳影片與播放清單資訊。
  • 公開 YouTube 影片的網址、標題、影片識別碼與發布資訊。
  • 為進行曲風分析而使用的公開 YouTube 影片內容或相關資訊。
  • 使用者在測試頁面輸入的 Gemini API Key，僅由瀏覽器直接傳送至 Gemini API，不由本網站儲存。

資料用途

資料只用於取得新影片、分析曲風、產生分類結果，以及代表使用者整理 YouTube 播放清單。資料不會用於廣告、販售或建立使用者個人檔案。

資料儲存與分享

OAuth 憑證與 API 金鑰儲存在 GitHub Actions Secrets，不會放在公開程式碼中。 GitHub Actions 工作流程可能在日誌中保留公開影片網址、標題與分析結果。 執行所需的資料會提供給 YouTube Data API、Gemini API，以及 GitHub Actions 執行服務。除上述必要服務外，不會將資料出售或提供給其他第三方。

資料保留與刪除

YouTube 資料會依照使用者的 Google 帳戶與播放清單設定保留。 使用者可以刪除 GitHub Actions Secrets、工作流程日誌或 YouTube 播放清單內容。 GitHub 與 Google 服務的資料保留則依各服務的政策與設定辦理。

撤銷授權

使用者可以在 Google 帳戶第三方連線設定 撤銷 yt_list 的 YouTube 授權。

聯絡方式

如有隱私相關問題，請至 yt_list GitHub Issues 聯絡。

Google API Services User Data Policy

yt_list 的 Google 使用者資料使用方式遵循 Google API Services User Data Policy 及其 Limited Use 要求。
